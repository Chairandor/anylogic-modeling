# AnyLogic 建模 Skill

[English](README.md)

这是一个供智能体使用的 Skill，用于在 Windows 上创建、编辑和验证原生 AnyLogic 仿真模型。

## 使用方法

将本仓库目录命名为 `anylogic-modeling`，复制到智能体的本地 Skills 目录。开发流程、参考文档和辅助脚本见 [SKILL.md](SKILL.md)。
