# AnyLogic Modeling Skill

[简体中文](README.zh-CN.md)

An agent skill for creating, editing, and validating native AnyLogic simulation models on Windows.

## Use the skill

Copy this directory as `anylogic-modeling` into your agent's local skills directory. See [SKILL.md](SKILL.md) for the workflow and links to the references and scripts.
